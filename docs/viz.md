# 条件触发式可视化调试面板

> `@openliulan/viz` —— AI 伦理透明化的核心组件。

## 设计理念

可视化调试面板遵循 **条件触发** 原则，是 AI 伦理的一部分：

- **不默认侵入**：除非用户明确声明"想看到调试"、"想一起测试"，否则不启动可视化。
- **透明化**：让用户能看到 AI 的执行决策（做了什么、为什么、下一步打算）。
- **可参与**：用户可以在关键决策点确认或干预 AI 的行为。
- **可追溯**：所有 AI 决策都有记录，用户可随时回看。

## 触发机制

```
用户声明 → viz.enable("user-requested-debugging") → 可视化开启
用户未声明 → viz 保持 off 状态 → 不产生任何可视化输出
```

三种模式：

| 模式 | 行为 |
| :--- | :--- |
| `off` | 完全关闭（默认） |
| `on-demand` | 初始关闭，用户声明需要调试时才启用 |
| `always` | 始终启用（教学/演示场景） |

## 核心功能

### 1. 记录 AI 决策

```ts
import { createViz } from "@openliulan/viz";

const viz = createViz({ mode: "on-demand" });

// 用户声明需要调试
viz.enable("user-requested-debugging");

// 记录 AI 决策（为什么这么做）
viz.recordDecision("导航到 example.com", "因为目标数据在该页面");
```

### 2. 请求用户确认（AI 伦理回环）

```ts
// AI 不确定或需要用户参与时，请求确认
viz.requestConfirmation("是否继续抓取下一页？", "页面可能有多页数据需要确认");

// 用户确认后
viz.confirm();
```

### 3. 生成可视化轨迹

```ts
// 渲染 Markdown 格式（供终端/消息显示）
const rendered = viz.render();
```

## 与 MCP 集成

Viz 模块可与 `@openliulan/mcp-server` 配合使用：
- 在 ForgeMcp 中注入 VizPanel，让所有工具调用自动记录到可视化轨迹；
- 通过 `session_log` 工具可以查看完整执行轨迹；
- 未来版本将支持 Web GUI 面板。

## AI 伦理的意义

可视化调试面板解决了 AI 自动化中的伦理问题：

1. **知情权**：用户有权知道 AI 在做什么、为什么这么做。
2. **参与权**：用户可以在关键决策点参与选择。
3. **解释权**：AI 的每个决策都有"为什么"的解释。
4. **控制权**：用户可以随时关闭可视化，随时干预 AI 行为。
